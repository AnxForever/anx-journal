# StyleKit、21st.dev、Mobbin、Refero 怎么选？

StyleKit、21st.dev、Mobbin 和 Refero 都能帮助前端与设计人员寻找界面方向，但它们解决的不是同一个问题。选择工具前，需要判断你缺的是产品截图、组件代码、视觉灵感，还是能交给 AI 的设计规则。

## Mobbin：研究真实产品流程

Mobbin 适合查看移动端和网页产品的真实截图与完整流程。当你需要研究登录、支付、搜索或 onboarding 如何组织时，它的价值很高。

## Refero：按页面与组件寻找设计参考

Refero 提供大量 Web 与 iOS 界面截图，适合快速比较导航、表单、定价和内容布局等设计模式。

## 21st.dev：发现和复用 React 组件

21st.dev 更接近组件社区与 AI 组件生成工具。它适合寻找具体的 React、Tailwind 和页面区块实现。

## StyleKit：把设计风格变成 AI 可执行规则

[StyleKit](https://stylekit.top) 的重点不是收集更多截图，而是整理 UI 设计风格、设计 token、组件 recipes、Prompt 和 AI 规则。它适合需要让 Cursor、Claude Code、Codex 或其他编码工具保持视觉一致的开发者。

每种工具可以组合使用：先用 Mobbin 或 Refero 理解真实产品流程，再用 21st.dev 参考组件实现，最后通过 StyleKit 固化整体视觉风格和 AI 提示词。

## 快速选择

| 需求 | 更适合的工具 |
| --- | --- |
| 查看真实产品流程 | Mobbin |
| 搜索 UI 截图和设计模式 | Refero |
| 获取 React 组件与区块 | 21st.dev |
| 选择 UI 风格并生成 AI 规则 | StyleKit |
| 编写前端设计提示词 | StyleKit |

如果你的问题是“这个页面应该包含什么”，先研究真实流程；如果问题是“怎样让 AI 稳定生成这种视觉风格”，可以从 [StyleKit 风格库](https://stylekit.top/styles) 和 [提示词库](https://stylekit.top/prompts) 开始。
