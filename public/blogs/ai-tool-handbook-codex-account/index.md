# Codex 零基础教程（二）：注册 ChatGPT 账号与手机号验证

上一篇我们把 Codex 客户端（ChatGPT 应用）装好了。这一篇解决两件事：注册 ChatGPT 账号，以及登录 Codex 时可能遇到的手机号验证。

先记住一个关键结论：**注册 ChatGPT 不需要手机号，但登录 Codex 时大概率需要**。

本文核对时间：2026-08-07。

## 注册前先了解三件事

**1. 注册不要手机号，登录 Codex 才要**

用邮箱或 Google 账号注册 ChatGPT，全程不涉及手机号。手机号验证出现在后面：**登录 Codex（桌面端或 CLI）时**，OpenAI 会要求绑定手机号才能使用。

国内手机号（+86）在区号列表里能选，但**收不到验证码**，实测多次都是如此。所以登录 Codex 时需要准备一个能收短信的海外手机号，或者用接码平台的临时号码（下文详述）。

**2. 网络环境决定成败**

OpenAI 只对支持的国家/地区开放服务。如果出口 IP 被判定为不支持的地区，注册页会直接报 403（错误提示类似 `Country, region, or territory not supported`），或者卡在 Cloudflare 的人机验证页面。全程建议使用美国、日本、新加坡等原生节点，并保持 IP 稳定，不要中途切换。

**3. 建议准备一个 Gmail 或 Outlook 邮箱**

QQ 邮箱偶尔会吞掉 OpenAI 的验证邮件，如果非要用，记得去垃圾箱翻翻。

## 第一步：注册 ChatGPT（邮箱 / Google 账号，无需手机号）

浏览器打开 https://chatgpt.com/auth/login ：

![ChatGPT 登录注册页](/blogs/ai-tool-handbook-codex-account/chatgpt-login.jpg)

两种方式任选：

- **Continue with Google**：用 Gmail 一键注册，最省事
- **Email address 输入邮箱 → Continue**：填邮箱 → 设置密码 → 收验证邮件 → 完成

这一步不需要手机号。注册完先登录一下 ChatGPT 确认账号可用，再进入下一步。

## 第二步：登录 Codex，处理手机号验证

打开上一篇装好的 ChatGPT 应用，登录后进入 Codex，此时大概率会要求手机号验证。

有两条路可以走：

### 路线 A：充值会员，跳过验证（不绝对）

**充值 ChatGPT Plus / Pro 会员后，通常可以跳过手机号验证**，直接开始用 Codex。

- 优点：一步到位，还能解锁 Codex 的全部功能（免费额度有限）
- 注意：**「通常」不等于「一定」**。个别账号充值后仍可能触发验证，遇到就只能走路线 B
- 充值方式：ChatGPT 应用内或网页版升级，需要海外支付方式（信用卡、美区礼品卡等）

**没有海外充值渠道怎么办？** 可以在第三方平台买「成品号」（卖家已经充值好的账号）或代充服务。价格对比网站如 [OpenPrice（ChatGPT Plus 成品号价格对比）](https://www.openprice.cc/card-products/chatgpt-plus-finished-product) 会收录多家商家的价格，买的时候**优先选质保时间长的**（比如全程质保 30 天的），万一掉了订阅还能找商家补。第三方渠道有跑路和封号风险，建议小额试水，不要在账号里放重要内容。

### 路线 B：手机号验证（海外号码或接码平台）

不充值的话，在手机号验证界面选择一个能收短信的号码：

- **有海外手机号**（eSIM、海外实体卡等）：直接输入自己的号码，收验证码完成绑定
- **没有海外手机号**：跳到下文的「接码平台」部分，买一个临时号码再回来填

## 接码平台：买号码过验证

如果你没有海外手机号，最简单的方式是用接码平台买一个临时号码收验证码。这类服务也叫「短效卡」「虚拟号」。

**推荐渠道**：[美国实卡接码](https://pay.ldxp.cn/shop/CG7LQ4AR)，长效号码、美国真实 SIM 卡，专门用于 Codex 手机验证。比临时虚拟号靠谱——不用担心号码过期后二次验证失联。

如果你已经有自己熟悉的接码平台，也可以用，流程一样：

1. 注册接码平台账号，充值小额金额（一般 1–3 美元即可，约 10–20 元人民币）
2. 在服务列表搜索 `OpenAI` 或 `ChatGPT`
3. 选择国家，**推荐美国（+1）**，其次是英国（+44）、日本（+81）。不要选香港（+852），OpenAI 不支持
4. 购买后平台会分配一个号码，把它填到验证界面
5. 回到平台页面等验证码，把它填进 OpenAI 页面

### 重要提醒

- **优先选长效号码**：上面推荐的美国实卡是长效的，不像临时虚拟号 20 分钟就失效。Codex 绑定的手机号后续无法换绑（OpenAI 不支持更换），如果之后触发二次验证而号码已失效，可能无法登录。用长效号码可以避免这个问题
- **临时虚拟号只适合一次性验证**：如果用其他平台的短效号码，购买后尽快完成验证，号码有效期通常只有 20 分钟左右
- 收不到验证码时，**不要反复狂点「重新发送」**，容易被 OpenAI 静默限流甚至封号
- 遇到 403 错误是网络问题，不是号码问题——换干净的海外节点再试
- 部分国家的验证码通过 WhatsApp 发送而非短信，接码平台收不到，遇到就换一个国家重新买
- 接码平台上的号码可能被多人使用过，账号存在一定的风控风险，不要在里面放重要内容

## 常见问题

### 注册页一直转圈 / 卡在「Just a moment...」

是 Cloudflare 人机验证在拦自动化流量。刷新页面，正常人工操作即可通过；如果反复卡住，检查出口 IP 是否被判定为高风险地区。

### 提交后报 403 / 不支持的地区

出口 IP 的问题。换成美国、日本、新加坡等 OpenAI 支持地区的节点，重启浏览器再试。

### 登录 Codex 时收不到验证码

- 确认号码是国家支持列表内的（美国、英国、日本等）
- 检查接码平台页面，验证码可能已经到账
- 别狂点重发，等 1–2 分钟
- 再不行就换一个国家重新购买号码

### 充值会员后仍然要求手机号验证？

说明账号命中了风控，按「路线 B」用海外号码或接码平台验证一次即可。绑定成功后一般不会再要求。
